# Plan chi tiết P2.1: Mục lục (`structure/toc.py`)

> Trạng thái: `Draft`, chờ duyệt · Thuộc: [Plan P2](plan.md)

## 1. Mục tiêu

Có **danh sách chương và bệnh theo mục lục**, kèm số trang in. Đây là "đáp án do chính sách cung cấp" để P2.2–P2.3 đối chiếu: số bệnh trong cây phải khớp mục lục, và trang bắt đầu của mỗi bệnh phải khớp số trang ghi trong mục lục.

## 2. Đầu vào / Đầu ra

- **Vào:** PDF, cấu hình `p2.toc`.
- **Ra:** `data/p2_tree/toc.json`

```python
class TocEntry(BaseModel):
    title: str            # "Viêm khớp dạng thấp" (đã sửa chuẩn hóa khoảng trắng, NFC)
    title_norm: str       # "viem khop dang thap" - bỏ dấu, chữ thường: chịu lỗi OCR mất/sai dấu
    level: Literal["chapter", "disease"]
    printed_page: int
    pdf_page: int | None  # = số trang in + độ lệch (lấy từ ánh xạ số trang của P1.2)
    toc_pdf_page: int     # trang mục lục chứa dòng này
    line_id: str          # truy vết
```

## 3. Thiết kế

1. **Tìm trang mục lục** (`pages: auto`): đọc `search_pages` trang đầu bằng `read_lines` (P1.1). Trang có ≥ `min_entries` dòng `toc_entry` (nhận diện bằng `blocks.classify_line`, dòng chấm dẫn + số cuối) là trang mục lục. Cấu hình `pages: [a, b]` thì dùng luôn.
2. **Phân tích từng dòng** `"<tiêu đề> ........ <số trang>"`:
   - Tách tiêu đề (bỏ dấu chấm dẫn) và số trang in.
   - **Cấp:**
     - khớp mẫu `CHƯƠNG n` / `Chương n` / `PHẦN n` → `chapter`;
     - còn lại → `disease`.
     - Kiểm tra chéo bằng **thụt lề**: bệnh thụt vào so với chương. Nếu mẫu chữ và thụt lề mâu thuẫn → cờ `level_conflict`.
   - Dòng mục lục bị **ngắt 2 dòng** (tiêu đề dài, số trang ở dòng sau): nối dòng không có số trang với dòng kế tiếp.
3. **Kiểm tra:**
   - Số trang in phải **không giảm** theo thứ tự. Nếu giảm → cảnh báo (OCR đọc nhầm số?).
   - Số trang in phải nằm trong phạm vi số trang in của sách.
4. **Ánh xạ sang trang PDF:** dùng độ lệch số trang của P1.2 (`map_printed_pages`). Đọc phần footer của các trang nội dung bằng `strip_furniture`, nên không phụ thuộc pilot.
5. **Không dùng LLM.** Mục lục có thể còn lỗi OCR (`Bệnh tiêu hỏa`); so khớp ở P2.2/P2.3 dùng `title_norm` (không dấu), nên lỗi dấu không ảnh hưởng.
