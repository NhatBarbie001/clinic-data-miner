# Plan chi tiết P1.1: Đọc PDF thành dòng (`ingest/pdf_reader.py`)

> Trạng thái: `Hoàn thành` (2026-10-20) · Báo cáo: [P1.1_report.md](P1.1_report.md) · Thuộc: [Plan P1](plan.md)

## 1. Mục tiêu

Đọc lớp text OCR của PDF thành danh sách `Line` **đúng thứ tự đọc**, đã **chuẩn hóa NFC**, có đủ đặc trưng trình bày (toạ độ, cỡ chữ, vùng trang) và **ID ổn định**. Đây là nền cho mọi bước sau.

## 2. Đầu vào / Đầu ra

- **Vào:** `data/raw/book01.pdf`, phạm vi trang (pilot hoặc toàn sách).
- **Ra:** `data/p1_clean/lines.jsonl`

```python
class Line(BaseRecord):                  # SCHEMA_VERSION 1
    page: int                             # số trang PDF
    index: int                            # thứ tự dòng trong trang (theo thứ tự đọc)
    text: str                             # đã NFC, gộp khoảng trắng thừa
    text_raw: str                         # nguyên văn từ PDF (có thể NFD)
    bbox: tuple[float, float, float, float]
    size: float                           # cỡ chữ trung bình theo ký tự
    font: str
    bold: bool
    zone: Literal["top", "body", "bottom"]
    page_height: float
    flags: list[str]                      # "nfd_fixed" nếu text_raw không ở dạng NFC
```

`id = stable_id(book_id, page, index, prefix="ln")`, giống với P0.5.

## 3. Thiết kế

- **Chuyển** `extract_lines` từ `ingest/survey.py` sang `pdf_reader.read_lines(pdf, pages=None)`. Lớp `SurveyLine` đổi thành `Line` (thêm `text_raw`, `flags`, `page_height`). `survey.py` import lại nên các test P0.5 không phải sửa.
- **Thứ tự đọc:** sắp các dòng theo `(page, y0 đã làm tròn 2pt, x0)`, không phụ thuộc thứ tự block mà PyMuPDF trả về. Cách này quan trọng với bảng: các ô cùng hàng sẽ nằm liền nhau, từ trái sang phải.
- **Chuẩn hóa:** `text = nfc(" ".join(raw.split()))`. Nếu `raw` không ở dạng NFC thì thêm flag `nfd_fixed`.
- **Lọc trang:** `pages=(start, end)` lấy từ pilot hoặc `--pages`. Ngoài phạm vi thì bỏ.
- **Phát hiện 2 cột** (chưa xử lý, chỉ cảnh báo): nếu một trang có hai cụm `x0` tách biệt rõ và mỗi cụm chiếm ≥ 30% số dòng thì ghi log cảnh báo `possible_two_columns`. Sách thật có thể cần xử lý (book_profile mục 9).
