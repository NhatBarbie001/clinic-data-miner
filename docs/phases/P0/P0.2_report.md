## 1. Đã làm gì

- `core/config.py`: schema `Settings` (Pydantic, khóa lạ bị từ chối), bộ nạp **4 lớp** (default → models → local → env) gộp sâu, che API key, `fingerprint()` cho manifest.
- **Thông báo lỗi tiếng Việt**, chỉ rõ khóa, lý do, giá trị nhận được, **file gây lỗi**, và gợi ý tên đúng khi gõ nhầm.
- `configs/models.yaml`: **mọi tác vụ dùng `deepseek/deepseek-v4.1-flash-1017`** theo quyết định của chủ dự án. Bật `reasoning` cho `extract`, `qa`, `judge`.
- Ngân sách: tổng $20, `ping` (P0) tối đa $1.
- CLI: `dm config show`, `dm config validate`.
- `find_project_root` chuyển từ `cli.py` sang `core/config.py`, vì `core` không được phụ thuộc `cli`.

## 5. Cách tự kiểm tra

```bash
uv run dm config validate                     # "Cấu hình hợp lệ ✓"
uv run dm config show                         # xem cấu hình cuối cùng
DM__LLM__CONCURRENCY=8 uv run dm config show  # concurrency đổi thành 8, fingerprint đổi
cp configs/local.example.yaml configs/local.yaml && uv run dm config show   # thấy lớp local.yaml
#   (xóa configs/local.yaml sau khi thử)
uv run pytest tests/unit/test_config.py -v    # 39 passed
```
Thử gõ sai một khóa trong `configs/local.yaml` rồi chạy `dm config validate` để xem thông báo lỗi.

## 7. Vấn đề và ghi chú

**Lỗi phát hiện khi xem output mẫu, đã sửa trước khi chốt:**
1. **Lỗi cấp nhóm chỉ sai nguồn.** `pilot` sai do `local.yaml` nhưng thông báo ghi `[nguồn: configs/default.yaml]`.
   - **Sửa:** chọn lớp *sau cùng* đã đặt bất kỳ khóa nào trong nhóm.
   - Thêm test `test_07c`.
2. **Còn thông báo tiếng Anh.** "String should have at least 1 character" và chữ "or" trong danh sách giá trị hợp lệ.
   - **Sửa:** dịch các thông báo này.
   - Thêm test `test_07d`.

**Quyết định đã đưa ra:**
- Tự viết bộ nạp (khoảng 150 dòng) thay vì dùng `pydantic-settings`. Lý do: kiểm soát được thông báo lỗi kèm nguồn và gợi ý tên khóa, không thêm thư viện.
- Fingerprint được tính **trước** khi resolve đường dẫn và thêm API key. Nhờ vậy cùng một cấu hình trên hai máy khác nhau cho cùng hash, và đổi key không làm đổi hash.
- Đường dẫn tuyệt đối trong `samples/` được thay bằng `<root>` để không lộ đường dẫn máy cá nhân.

**Lưu ý / tồn đọng:**
- ⚠️ **`judge` dùng cùng model với `qa` và `datagen`.** Model có xu hướng chấm điểm cao cho output của chính mình (self-preference bias), làm số đo độ trung thực ở P5/P7 kém tin cậy. **Đề xuất:** trước P5, đổi `judge` sang một model khác họ. Chỉ cần sửa một dòng trong `models.yaml`.
- Model ID `deepseek/deepseek-v4.1-flash-1017` **chưa được xác nhận** trên OpenRouter. Sẽ kiểm tra ở P0.3 (`dm llm models`, cần API key).
- Các thông báo hiếm gặp của Pydantic có thể vẫn là tiếng Anh. Những loại lỗi phổ biến đã được dịch.
